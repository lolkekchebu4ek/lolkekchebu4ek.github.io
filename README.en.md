# NOIR STUDIO

This project is a bilingual landing page and a case study in process clarity. It demonstrates how a portfolio site can evolve from a rough idea into a working but imperfect showcase.

## Project structure
- `index.html` — language selector page
- `ru/index.html` — Russian version of the landing page
- `en/index.html` — English version of the landing page
- `assets/` — shared styles, scripts, and content
- `docs/` — supporting documentation and case-study material
- `experimental/` — prototype or non-production drafts

## Language entry points
This repository now includes two visible entry points:
- Russian: `/ru/`
- English: `/en/`

## What is done
- working bilingual landing page
- language switching flow
- shared assets to reduce duplicate logic
- separate entry points for different audiences
- honest case-study framing with clear limits and trade-offs

## What still needs improvement
- some copy can be refined for a more premium tone
- final browser QA should still be run on the live Pages URL
- Lighthouse and screenshot checks should be added after deployment

## Main lesson
The real value of this project is not only the polished design, but the honest account of how a vague brief leads to constant rework. This branch is a functional demonstration and a useful example of why clear technical specifications matter.
