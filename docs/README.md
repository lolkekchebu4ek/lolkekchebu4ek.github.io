# Project structure

This repository keeps the live landing page at the root so it can serve cleanly on GitHub Pages or any static host.

Secondary material is stored in dedicated folders so the main experience remains focused and easy to scan:

- `docs/` — project documentation, process notes, and case-study material
- `experimental/` — older prototypes, experiments, or non-production drafts

The root project remains the public-facing landing page and the main entry point.
